# Brass: Birmingham 联机版 · 项目介绍与操作指南

一个**自托管**的《Brass: Birmingham》联机实现：浏览器与朋友对局（局域网/公网均可），支持 AI 座位、回合确认与撤销、全量落库回放。本文档面向玩家与维护者，介绍它的玩法操作、界面特色与调试工具。

## 快速开始

```bash
npm install
npm run build -w @brass/web
cd packages/server && WEB_DIST=../web/dist npx vite-node src/main.ts
# → 打开 http://localhost:8420
```

- 单端口托管：静态页面与 WebSocket 同在 `:8420`,SQLite 存于 `packages/server/brass.db`
- 大厅创建房间(可选 2/3/4 人、AI 座位数、8 位种子可重随),把 6 位房间号发给朋友
- 环境变量:`PORT`、`DB_PATH`、`WEB_DIST`、`ANTHROPIC_API_KEY`(无则 AI 用内置启发式)、`BRASS_AI_PACE_MS`(AI 行动节奏,默认 5000)、`BRASS_ROUND_BREAK_MS`(轮末停顿,默认 5000)

## 对局操作与界面特色

### 回合流程:确认与撤销

- 每个玩家的回合打满后进入**扣回合窗口**:显式「结束回合」放行,或「重置本回合」整回合撤销重来(红色提醒样式)。
- **结算严格滞后**:补牌、顺位重排、收入、时代清算,全部在点击结束回合后才发生。此前其他玩家只能看到行动播报与你版图上的行动记录,钱轨/顺位/轮次/手牌一概不动。
- **轮末停顿**:收官玩家结束回合后,全场播「第 x 轮结束」并停 5 秒,期间末位玩家版图仍展示本轮行动,到点再放行下一位。

### 行动交互

- **建造**:选牌后点地图城市/槽位,或宽屏下从个人版图把产业 token **拖到目标城市**(带容错吸附,歪一点也能落下);拖到版图垃圾桶 = 研发。暂存期间版图上对应栈顶 token 消隐。
- **连接(铺路)**:点选连线;铁路时代双轨 £15 + 1 酒。双轨选酒后出现**酒源选择行**(自家任意酒厂 / 连通第二条的对手酒厂,不可用商人桶),按钮/地图高亮/点图等价,单桶自动选中。
- **出售**:可一键全卖(规范化最优配对),也可分组自选:板块 → 贸易商 → 逐桶选酒(自家酒厂无需连通,对手酒厂须连通,商人桶给奖励)。**已收组的酒桶实时从后续组可选项里扣掉**;点下一块待售板块自动收下当前组。地图高亮圈出真能收货的商人与可用酒桶。
- **商人桶规则**:桶绑在具体商人板块格旁(精确图标或万能格才收对应货),格洛斯特(免费研发)触发时行动栏让你**自选研发产业**(或拖板块到垃圾桶),其余奖励(VP/钱/收入)自动结算。
- **搜寻(Scout)**:弃 3 张换 2 张百搭;打出的百搭也会留在你的打出记录里。

### 信息展示

- **三牌堆**(地图左侧凹槽):待摸牌堆(大数字余量,结束回合 -2)、万能产业、万能城市(大步进错位,逐张可辨)。
- **飞牌特效**:结束回合后补牌从牌堆飞向你(他人飞向其版图);搜寻时百搭各飞一张;打出百搭飞回供应堆;重置回合全部即时还原。
- **个人版图**:顺位/金钱/本回合行动(含实际盈亏,绿色收入红色支出,±0 也显示)/历史轮次(轮标签附「收入 ±£N」);「打出」弹窗按序展示本时代全部出牌(含百搭与中文名)。
- **行动日志**:两种风格(上下分隔 / 按回合分组,偏好设置切换),每轮一行卡牌(搜寻 4 张一行)+ 行动与盈亏,卡牌均有中文名。
- **分数构成**:各时代末构成表(连接分/产业分)+ **暂定总分(实时)**:轨迹分 + 当前连接分 + 当前翻面产业分;运河时代双列(至运河末 / 含铁路末 ≥2 级翻面再计一次);终局时轨迹列显示前段累计,合计=轨迹分。
- **提示卡**:按当前人数列出各城市/产业卡牌数,附原版提示卡大图。
- **回合播报**:每位玩家行动全场高亮脉冲 5 秒,顶部显示时代与「第 x/y 轮」。

### AI 座位

- 创建房间时可设 AI 座位数与难度(普通/困难);`ANTHROPIC_API_KEY` 缺失时降级为内置启发式,对局永不卡死。
- AI 行动有节奏(默认 5 秒/步)与「AI 思考中」指示;终局后可自由翻看全部版图与记录(不再跳终局画面)。

### 断线与恢复

- 刷新/断线自动 resume 回座位;服务器重启后按 SQLite 行动日志重放恢复(进行中与已终局对局均可)。
- 同一 token 在第二个标签页打开会提示「连接被接管」,可抢回。

## 调试工具

- **快进脚本** `npm run drive -w @brass/server -- --room CODE --to TARGET`:
  用启发式离线把对局快进到目标状态写入库,重启/resume 生效。
  `TARGET`:`last-canal-round`(默认)/ `last-rail-round` / `canal:N` / `rail:N` / `+N`;
  `--no-ai` 清零 AI 座位(默认保留,AI 自然行动到人类座位停下);`--db` 指定库文件。
- **对局存档**:`packages/server/test/fixtures/games/` 存放完整对局记录(config + 全量行动),
  `replay-fixture.test.ts` 会重放校验里程碑与终局,引擎语义漂移会立即暴露。
- 直接改库回退/快进(如删 `actions` 表尾部)亦可,改完需重启服务器让内存会话按库重放。

## 架构速览

- `packages/engine`:确定性规则引擎(纯函数,`newGame(seed)` + 逐条 `applyAction` 可重放出完全一致的状态)。
- `packages/server`:权威服务器(房间/token/ws/SQLite),结算时序(扣回合/轮末挂起/时代清算延迟)在此收口。
- `packages/web`:React 客户端(SVG 版图、行动栏、个人版图、弹窗层),隐藏信息由协议层过滤。
- `packages/llm`:LLM 决策链(局面摘要 → 候选筛选 → Claude 工具调用 → 引擎校验 → 启发式兜底)。
